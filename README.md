# Meal Wheel · 温润的餐桌

A tiny static web app that picks 6 dishes a day (3 meals × protein + carb) from a 1400-dish Chinese/Western library. The system picks; you only accept or swap individual dishes.

## Stack

- Pure HTML + CSS + vanilla JS (ES modules)
- No build step
- Vitest for unit tests (algorithm only)
- PWA-enabled: install to home screen on iOS / Android
- Hosted on GitHub Pages

## Local development

```bash
# 1. Install test deps
npm install

# 2. Run tests
npm test

# 3. Serve the app locally
python3 -m http.server 8000
# Open http://localhost:8000
```

## Updating the recipe library

The recipe library lives outside this repo at `~/Documents/饮食菜品库/`. After editing those `.md` files:

```bash
python3 scripts/sync_dishes.py    # rebuilds data/dishes.json
git add data/dishes.json
git commit -m "data: <what changed>"
git push                            # auto-deploys to GitHub Pages in ~10s
```

## Deployment

The app is deployed to **https://suunto.github.io/meal-wheel/** via GitHub Pages.

To set up from scratch on a new machine:

1. `git clone` this repo
2. `npm install`
3. `python3 scripts/sync_dishes.py` (regenerates the dish JSON from your local library)
4. Edit the GitHub Pages source in repo Settings → Pages → `main` branch, root.
5. Push to `main`; GitHub deploys automatically.
